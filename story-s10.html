地球生存遊戲・最終季・世界區域與總整理

高中地理只有一個故事

小禾帶著九層地圖環遊世界。每到一個地方，他都用同一條因果鏈解開它的祕密。

主要角色：小禾（被拉進遊戲的高中生）、地球（出題的關主）、羅盤（會說話的嚮導）。角色與情節為虛構，地理概念依部定必修課程。

S10・E1巡迴一

季風亞洲：同一條鏈

螢光底＝要記的名詞，藍色數字＝要記的數字；灰底是角色說的話

第一站・恆河、長江、湄公河

地球：「這裡為什麼擠滿了人？」

小禾翻開第三層（雨量）和第六層（農田）：「季風帶來夏雨，雨熱同期適合水稻，一塊田養很多人，所以人口密集。」

中國東部平坦、季風濕潤，人口東密西疏；華北人口多卻缺水，所以有南水北調。1978 年改革開放後設立經濟特區，深圳從漁村變成世界工廠。

東南亞的新加坡扼守麻六甲海峽，成了轉運港；印度的班加羅爾靠英語人才和時差，成了軟體重鎮。

本集重點

  • 季風 → 雨熱同期 → 水稻 → 人口密集，是季風亞洲的共同骨架。
  • 中國：東密西疏、南水北調、改革開放與經濟特區。
  • 新加坡（麻六甲海峽轉運）、印度班加羅爾（資訊服務業）。
下集預告往西飛，綠色的稻田不見了，窗外變成一片黃沙。

看完考一下

Q1中國進行南水北調的主因是？
看解析
B。華北降水少、需求大；長江流域水量豐沛。
Q2新加坡發展成轉運港最關鍵的條件是？
看解析
B。麻六甲海峽連接印度洋與太平洋。
S10・E2巡迴二

乾燥世界：高壓與石油

螢光底＝要記的名詞，藍色數字＝要記的數字；灰底是角色說的話

第二站・沙漠與綠洲

小禾翻開第二層：「北非和西亞在副熱帶高壓底下，空氣下沉，所以是沙漠。農業只能靠綠洲和尼羅河谷，其他地方游牧。」

波斯灣底下有大量石油。產油國靠石油致富，又怕油用完、油價跌，所以杜拜轉型發展金融、觀光和航空轉運。

河流跨越很多國家，上游建壩、下游擔心，像尼羅河上的衣索比亞大壩。

第三站・漠南非洲

非洲很多國界是直線，那是殖民列強在地圖上畫的。殖民也留下了單一作物經濟：迦納、象牙海岸靠可可，價格一跌，國家就受傷。

羅盤：「資源多不等於富有。附加價值和價格穩定，才是關鍵。這是第九季的核心與邊陲。」

本集重點

  • 西亞北非：副熱帶高壓→ 沙漠 → 綠洲、游牧；石油經濟與產業多角化（杜拜）。
  • 國際河川上游建壩引發水權爭議（尼羅河）。
  • 漠南非洲：殖民的直線國界、單一作物經濟、人口快速成長。
下集預告往北飛到歐洲。同樣是高緯度，倫敦的冬天卻比莫斯科暖和得多。

看完考一下

Q3西亞北非大部分地區乾燥，主要受什麼影響？
看解析
B。回歸線附近的副熱帶高壓下沉乾燥。
Q4迦納經濟高度依賴可可出口，最大的風險是？
看解析
A。單一作物經濟受國際價格影響很大。
S10・E3巡迴三

歐洲與俄羅斯：暖流和凍土

螢光底＝要記的名詞，藍色數字＝要記的數字；灰底是角色說的話

第四站・西歐

小禾翻開第二層：「西風把北大西洋暖流上方的溫暖空氣吹進來，所以西北歐冬暖夏涼、全年有雨。越往東，離海越遠，越乾冷。」

德國魯爾區靠煤礦和萊茵河發展重工業，煤鐵衰退後轉型。歐盟拆掉國界的關稅，用歐元、開放申根免邊檢；英國在 2020 年脫離歐盟。歐洲高齡少子，需要外來移民補勞力。

第五站・俄羅斯

俄羅斯又大又冷，西伯利亞滿是針葉林和凍土，人口集中在比較溫和的西部。經濟靠石油和天然氣出口。

全球暖化讓北冰洋的海冰變少，北極航道開始有船走，亞洲到歐洲的路變短了。

本集重點

  • 西歐：西風＋暖流 → 溫和多雨；往東大陸性增強。
  • 魯爾區（煤＋萊茵河）轉型；歐盟：單一市場、歐元、申根，英國已脫歐。
  • 俄羅斯：大而冷、人口在西部、依賴能源出口；暖化使北極航道受關注。
下集預告最後一站：美洲和大洋洲。地球說：「這裡的山，是直的。」

看完考一下

Q5倫敦冬季比莫斯科溫和，主要原因是？
看解析
B。西風把暖流上方的暖空氣吹進西歐；莫斯科深入內陸。
Q6全球暖化對北極航道的影響是？
看解析
B。夏季海冰減少，北方航線變得可行。
S10・E4巡迴四

美洲與大洋洲：直的山

螢光底＝要記的名詞，藍色數字＝要記的數字；灰底是角色說的話

第六站・北美

北美的洛磯山和阿帕拉契山都是南北走向，中間是大平原。北方的冷空氣和墨西哥灣的暖濕空氣可以直接在平原相撞，所以龍捲風特別多。

大平原是機械化的商業性穀物農業。五大湖的老工業區衰退，溫暖、成本低的南部陽光帶興起；矽谷則是高科技群聚。

第七站・中南美與大洋洲

安地斯山從山腳到山頂，氣溫一路下降，作物從熱帶水果換成玉米、馬鈴薯，叫垂直氣候。亞馬遜雨林為了牧場和大豆被大片砍伐。

澳洲內陸在副熱帶高壓底下，又乾又熱，人口擠在東南沿海；鐵礦和煤大量賣到亞洲。太平洋島國最怕海平面上升。

本集重點

  • 北美山脈南北走向 → 冷暖氣團交會 → 龍捲風；鏽帶衰退、陽光帶興起、矽谷群聚。
  • 安地斯垂直氣候；亞馬遜為牧場與大豆砍伐。
  • 澳洲內陸乾、人口在東南；太平洋島國怕海平面上升。
下集預告九層地圖疊在一起，只剩下一條線。

Q7美國大平原龍捲風多，與地形的關係是？
看解析
B。沒有東西向山脈阻擋，冷暖空氣在平原相遇。

看解析

S10・季末總整理世界區域與總整理

《只有一個故事》

這一季的劇情，用旁白的方式從頭說一次。粗體是要記的名詞。

小禾把九層地圖疊在一起：經緯線、氣壓帶與風帶、雨量、河流與地形、人口、農田、工廠、城市、航線。地圖突然只剩下一條線。

太陽 → 氣候 → 自然環境 → 農業 → 人口 → 都市 → 產業 → 貿易 → 全球化

太陽不公平地加熱地球，造出氣壓帶和風；風帶著水撞上山，下成雨；雨變成河，雕出平原和三角洲。人類選擇住在平原和水邊，種下適合氣候的作物；人多了，就有城市和工廠；交通進步以後，全世界連在一起。

環遊世界時，每個區域都是這條線的一段：季風亞洲是季風 → 水稻 → 人口密集；西亞北非是副熱帶高壓 → 沙漠 → 綠洲與石油；西歐是西風 → 暖流 → 溫和多雨；北美是南北向山脈 → 冷暖氣團交會 → 龍捲風。

地球：「最後一題。以後遇到陌生的題目，你要先問什麼？」

小禾想了想：「不是問『這個我有沒有背過』，而是問：『它在這條因果鏈的哪一段？』」

地球：「恭喜過關。」

只背一條劇情骨架

太陽 → 氣候 → 自然環境 → 農業 → 人口 → 都市 → 產業 → 貿易 → 全球化；遇到陌生題目，先找它在這條鏈的哪一段。

切成四幕來記

第一幕自然太陽、氣候、地形、水
第二幕人人口、農業、都市
第三幕經濟產業、貿易、全球化
第四幕世界每個區域都是鏈的一段

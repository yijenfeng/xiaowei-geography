地理藍圖

開始讀之前，先看整張地圖。高中地理三冊、十二個單元，其實只在講一件事：地球給了條件，人類做出選擇。之後每讀一課，都回來看看它在這張圖的哪一格。

這一節回答一個問題：「高中地理到底在學什麼？」

PART 1 ・ 一句話

地理只問三個問題

① 在哪裡？先定位：緯度、海陸、地形高低
② 為什麼在那裡？用自然條件解釋：氣候、地形、水
③ 會造成什麼？推到人類：人口、農業、產業、貿易
每一題都能照這個順序想。題目給你一個地方、一張圖或一段新聞，先問「在哪裡」，再問「為什麼」，最後問「會怎樣」。
PART 2 ・ 藍圖

一張圖：三幕、七個問題

第一幕　地球出題自然地理・第 1–4 週

地球先決定這個地方的條件：在哪裡、多冷多熱、多乾多濕、地形和水長什麼樣子。

1・位置我在哪？經緯度、時差、比例尺、等高線、GIS地理技能 →故事 S1
2・氣候冷還是熱？乾還是濕？太陽、氣壓與風、季風、洋流、氣候圖天氣與氣候 →氣候圖速查 →故事 S2故事 S3
3・地形與水地表長什麼樣？水去哪？板塊、河流三段、海岸、淹水、土壤地形 →水文與生態 →故事 S4
自然條件，決定人類能怎麼生活
第二幕　人類作答人文地理・第 5–8 週

人類在這些條件下做選擇：住哪裡、種什麼、做什麼工作、怎麼和世界做生意。

4・人口與都市人住在哪？人口分布、人口轉型、遷移、都市、中地人口與聚落 →故事 S5故事 S8
5・農業吃什麼？水稻與小麥、集約與粗放、杜能、栽培業農業 →故事 S6
6・工業做什麼工作？區位導向、外移、群聚、微笑曲線工業與服務業 →故事 S7
7・全球化怎麼跟世界連？時空壓縮、國際分工、核心邊陲、區域整合全球化與區域發展 →故事 S9
把前兩幕放到世界各地
第三幕　各地的答案卷世界區域・第 9–12 週

每個區域都是同一條鏈的一個例子。讀區域時，只要找出它的「第一個原因」，後面都推得出來。

區域季風亞洲季風 → 水稻 → 人口密集讀教材 →故事 S10
區域乾燥世界副熱帶高壓 → 沙漠 → 綠洲、石油讀教材 →故事 S10
區域歐洲與俄羅斯西風＋暖流 → 溫和多雨；越往東越冷讀教材 →故事 S10
區域美洲與大洋洲南北向山脈 → 冷暖氣團相撞；澳洲內陸乾讀教材 →故事 S10

一行背起來：我在哪 → 冷熱乾濕 → 地表與水 → 人住哪 → 吃什麼 → 做什麼工作 → 怎麼連上世界

PART 3 ・ 走一次

用台灣把整條鏈走一遍

  1. 1 位置北緯約 23°–25°，在亞洲大陸東邊、太平洋西邊北回歸線經過，又是大陸和大洋的交界
  2. 2 氣候夏天吹西南季風、有颱風；冬天吹東北季風北部冬天迎風多雨，南部冬天背風乾燥
  3. 3 地形與水板塊擠壓，山又高又陡；河短流急，西部堆出沖積平原這也是為什麼台灣多地震、易有土石流
  4. 4 人口人口集中在西部平原平坦、有水、交通方便
  5. 5 農業高溫多雨，適合種水稻季風 → 雨熱同期 → 水稻 → 養活很多人
  6. 6 工業人才、大學、供應鏈聚在新竹 → 半導體群聚勞力密集的工廠則外移到東南亞
  7. 7 全球化晶片賣到全世界，台灣在全球供應鏈的關鍵位置所以國際情勢一變，台灣就受影響
這就是學測題的樣子。一個題組常常從其中一格開始，再往前或往後問一兩格。你只要知道自己站在哪一格，就知道下一步往哪裡推。
PART 4 ・ 怎麼用

讀每一課時做三件事

  • 開課前：看頁面最上面的「藍圖位置」，知道這一課在第幾格。
  • 讀的時候：問自己「它的原因在前一格的哪裡？它會影響後一格的什麼？」
  • 寫題目時：不要先問「這個我有沒有背過」，而是問「它在這條鏈的哪一段」。
  • 想先聽故事：《地球生存遊戲》把這七格拍成十季連續劇，每一季對應藍圖的一格。

動手試試看

選擇題點選答案、簡答題按「對答案」，作答紀錄會保留在這台裝置。
Q1「撒哈拉為什麼是沙漠？」這個問題在藍圖的哪一格？
看解析
B。乾不乾是氣候問題：撒哈拉在副熱帶高壓底下，空氣下沉，所以乾燥。
Q2「為什麼沖積扇的扇端有湧泉？」在哪一格？
看解析
B。這是河流堆積與地下水的問題，屬於「地表長什麼樣、水去哪」。
Q3「為什麼成衣廠從中國搬到越南？」在哪一格？
看解析
C。工廠設在哪裡、為什麼搬家，是工業區位的問題。
Q4「為什麼季風亞洲人口特別多？」最完整的想法是？
看解析
C。季風帶來雨熱同期 → 適合水稻 → 單位面積養活很多人 → 人口密集。一題橫跨三格，這正是藍圖的用法。
Q5讀到一個沒學過的地方，第一步最應該做什麼？
看解析
B。地理的第一個問題永遠是「在哪裡」，位置會一路影響後面每一格。
Q6用藍圖的順序，說明為什麼台灣西部的人口比東部多。
看參考答案與解析

台灣東部山地多、平地少；西部有河流堆積出的沖積平原，地勢平坦、有水、交通方便，適合耕作與居住，所以人口集中在西部。

從「地形與水」那一格開始，推到「人住哪」那一格。

系統只檢查是否寫到關鍵詞：平原 / 沖積 / 平坦　人口 / 集中 / 居住 / 聚落（每組至少寫到一個）。寫得通順、因果清楚才是得分關鍵，請對照參考答案。

本節重點
  • 地理只問三個問題：在哪裡、為什麼在那裡、會造成什麼。
  • 三幕：地球出題（自然）→ 人類作答（人文）→ 各地的答案卷（區域）。
  • 七格：我在哪 → 冷熱乾濕 → 地表與水 → 人住哪 → 吃什麼 → 做什麼工作 → 怎麼連上世界。
  • 遇到陌生題目，先找它在哪一格，再往前找原因、往後推影響。

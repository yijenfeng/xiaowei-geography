水文與生態

第 4 週。水和生態的題目常和人類活動綁在一起：都市淹水、地層下陷、雨林砍伐、沙漠化。

這一節回答一個問題：「人類改變了地表，水和生物會怎麼反應？」

PART 1 ・ 水循環

人類一動地表，水就換一條路走

  1. 循環蒸發 → 水氣輸送 → 降水 → 逕流或入滲 → 回到海洋入滲的水補充地下水，逕流的水進入河川
  2. 都市化柏油、水泥增加不透水面入滲減少、地表逕流增加 → 洪峰更高、更早出現 → 都市淹水
  3. 超抽地下水抽取量大於補注量地層下陷 → 沿海低地易淹水、海水入侵，台灣西南沿海養殖區最明顯
  4. 對策海綿城市、透水鋪面、滯洪池、地下水管制讓水「慢下來、留下來」
河川補給流量變化例子
季風雨夏季豐水、冬季枯水長江、恆河
全年雨流量穩定亞馬遜河、剛果河
冬雨（地中海型）冬季豐水、夏季枯水地中海沿岸河川

PART 2 ・ 植被與土壤

氣候決定植被，植被影響土壤

植被對應氣候土壤利用與問題
熱帶雨林熱帶雨林紅壤，淋溶強、養分少生物多樣性最高；砍伐開牧場、種大豆和油棕
莽原熱帶莽原乾季明顯稀樹草原、野生動物觀光
沙漠沙漠鹽分易累積綠洲農業；灌溉不當會鹽鹼化
溫帶草原溫帶大陸性（半乾燥）黑土，腐植質多、最肥沃世界穀倉：烏克蘭、北美大平原、阿根廷
針葉林高緯寒冷灰化土，酸性林業：西伯利亞、加拿大
苔原寒帶凍土地衣、苔蘚；暖化使凍土融化
觀察

熱帶雨林看起來很茂盛，土壤卻很貧瘠：高溫多雨讓養分很快被沖走，養分大多存在植物身上。雨林一砍，土地幾年就不能種了。

練習

動手試試看

選擇題點選答案、簡答題按「對答案」，作答紀錄會保留在這台裝置。
Q1某地快速都市化後，遇到同樣的降雨，河川洪峰會如何變化？
看解析
B。不透水面增加，雨水入滲少、很快流進河川，洪峰變高、出現時間提早。
Q2熱帶雨林的土壤貧瘠，主要原因是？
看解析
B。大量雨水把土壤中的養分往下沖走，只留下鐵、鋁氧化物，土壤偏紅而貧瘠。
Q3烏克蘭、北美大平原成為世界穀倉，與哪一種土壤有關？
看解析
C。溫帶草原的草每年枯死，累積大量腐植質，形成肥沃的黑土。
Q4撒哈拉沙漠南緣薩赫爾地區沙漠化嚴重，主要原因是？
看解析
B。氣候本來就半乾燥，人口增加後過度放牧、墾殖、砍柴，使植被消失、土地退化。
Q5台灣西南沿海地層下陷，最主要的人為原因是？
看解析
B。養殖業與農業大量抽地下水，含水層被壓密，地面下沉。
Q6「海綿城市」如何減少都市淹水？
看參考答案與解析

用透水鋪面、綠地、滯洪池讓雨水入滲或暫時儲存，減少地表逕流、降低並延後洪峰，就不容易淹水。

寫出「入滲／暫存」這個方法，再寫出「逕流減少」這個結果。

系統只檢查是否寫到關鍵詞：入滲 / 滲透 / 透水 / 吸收 / 綠地　逕流 / 滯洪 / 儲 / 洪峰 / 暫存（每組至少寫到一個）。寫得通順、因果清楚才是得分關鍵，請對照參考答案。

本節重點
  • 都市化 → 不透水面增加 → 逕流多、洪峰高且早。
  • 超抽地下水 → 地層下陷；對策是管制抽水、找替代水源。
  • 雨林土壤貧瘠（淋溶），溫帶草原黑土最肥沃。
  • 沙漠化 = 乾旱 + 人為過度利用，薩赫爾最典型。

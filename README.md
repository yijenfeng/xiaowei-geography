# 筱葳學測地理

2027 學測社會科地理的 14 週學習地圖與線上教材。從 `index.html` 進入。

- 70 分速成（fast70.html、f70-1…8.html）：依 111–115 學測地理題的分數分布，六個核心單元佔 71%；八課各有得分招式（觸發字→解法→歷屆題實例）、名詞速配、練習與口訣，另有 40 張名詞速配卡
- 第 0 課・地理藍圖：三幕、七個問題，一張圖看懂高中地理的脈絡；每份教材頂端標出「藍圖位置」
- 學測常考國家（top-countries.html）：依 111–115 學測地理題統計的 14 個常考國家，總表、七步說明與歷屆題連結，供考前快速複習
- 世界地圖學習工具：Natural Earth 國界底圖，四個圖層（定位、氣候、地形與洋流、人文與經濟）、176 個國家與地區的七步說明（位置、氣候、地形與水、人口、農業、工業、全球化）、20 個學測重點地方、找國家測驗、學測推理題
- 作答技能：圖表判讀四步驟、混合題作答法
- 自然地理、人文地理、世界區域共 12 個單元教材（因果鏈、比較表、題目線索速查、附解析練習）
- 氣候圖速查：十一種氣候的氣候圖，可遮住答案自我測驗
- 主題串連：季風、副熱帶高壓、板塊、產業鏈、水資源
- 歷屆試題練習：111–115 學測社會考科的地理題，線上作答、自動批改（試題來源：大考中心）
- 歷屆試題紀錄、錯題本

學習進度與作答紀錄只存在各自裝置的瀏覽器裡。

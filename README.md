# 筱葳學測地理

2027 學測社會科地理的 14 週學習地圖與線上教材。從 `index.html` 進入。

- 第 0 課・地理藍圖：三幕、七個問題，一張圖看懂高中地理的脈絡；每份教材頂端標出「藍圖位置」
- 作答技能：圖表判讀四步驟、混合題作答法
- 自然地理、人文地理、世界區域共 12 個單元教材（因果鏈、比較表、題目線索速查、附解析練習）
- 氣候圖速查：十一種氣候的氣候圖，可遮住答案自我測驗
- 主題串連：季風、副熱帶高壓、板塊、產業鏈、水資源
- 歷屆試題練習：111–115 學測社會考科的地理題，線上作答、自動批改（試題來源：大考中心）
- 歷屆試題紀錄、錯題本

學習進度與作答紀錄只存在各自裝置的瀏覽器裡。

大家開始往城市跑

工作在城市，人就往城市跑。人一多，房價、塞車、污染跟著來，於是人又開始往外搬。

任務 8-1・一座城長大

工廠需要工人，商店需要店員，辦公室需要職員。工作集中在城市。

農村的年輕人坐上火車、坐上巴士：農村人口 → 城市。

羅盤：「住在都市的人口比例變高，叫都市化。」

城市越長越大：都市 → 都會區 → 都市帶。

任務 8-2・人一多，問題就來

房價上升、塞車、污染、都市蔓延。有錢的人開始搬到郊外，叫郊區化。

羅盤：「都市地理不要背一堆名詞，它其實是一個故事：工作吸引人口 → 人口集中 → 都市擴張 → 問題產生 → 人口與功能重新分布。」

本集重點

  • 都市化＝都市人口比例提高；工作集中吸引人口。
  • 城市成長：都市 → 都會區 → 都市帶。
  • 故事：工作吸引人口 → 集中 → 擴張 → 問題 → 重新分布（郊區化）。
下集預告同樣是都市化，在拉丁美洲和在歐洲，長出來的城市完全不同。

S8・E2第二關

兩種城市

任務 8-3・拉丁美洲的大城

在拉丁美洲和許多開發中國家，鄉村生活很苦，大家一起湧進最大的那座城市。

人來得比工作和房子還快，城市外圍蓋滿了簡陋的房子，叫貧民窟。

羅盤：「人口增加的速度超過工作和設施，叫過度都市化。一座城大到其他城市都比不上，叫首要城市，像曼谷。」

任務 8-4・歐洲的老城

在已開發國家，都市化程度早就很高，速度慢了下來。問題變成內城老舊、房價太高。

羅盤：「他們的對策是都市更新和大眾運輸。舊區更新以後房租變貴，原本的居民被迫搬走，叫仕紳化，常常引起爭議。」

本集重點

  • 開發中國家：過度都市化、貧民窟、首要城市（鄉村推力大於都市工作）。
  • 已開發國家：都市化程度高、速度慢；郊區化、都市更新、仕紳化。
  • 學測常比較拉丁美洲與歐洲的都市規模結構。
下集預告鄉下到處都有便利商店，可是百貨公司只在大城市。地球問：「為什麼？」

便利商店和百貨公司

任務 8-5・門檻

地球：「為什麼每個村子都有便利商店，百貨公司只在台北？」

羅盤：「一家店要活下去，需要最少的顧客數，叫門檻人口（商閾）。便利商店賣日用品，門檻低；百貨公司賣貴的東西，門檻高。」

羅盤：「顧客願意跑多遠來買，叫服務範圍（商品圈）。去醫學中心看病，大家願意跑很遠。」

任務 8-6・中地的金字塔

提供商品和服務的地方叫中地。高級中地（台北）數量少、彼此距離遠、什麼都有；低級中地（鄉鎮）數量多、只有日常用品。

羅盤：「交通變方便以後，大家願意跑更遠，高級中地吸走更多顧客，鄉鎮的一些商店就關門了。」

小禾的地圖多了第八層：城市。

本集重點

  • 中地：提供商品與服務的聚落。
  • 門檻人口（商閾）：店家存活的最少顧客數；服務範圍（商品圈）：顧客願意前往的距離。
  • 高級中地少、遠、門檻高、範圍大；交通改善使高級中地更強。

S8・季末總整理都市與聚落

《城市的一生》

這一季的劇情，用旁白的方式從頭說一次。粗體是要記的名詞。

工作集中在城市，人就往城市跑。都市人口比例提高，就是都市化；城市長成都會區，再連成都市帶。

工作吸引人口 → 人口集中 → 都市擴張 → 問題產生 → 人口與功能重新分布

人一多，房價、塞車、污染都來了，有人搬到郊外，叫郊區化。

同樣是都市化，結果不一樣。開發中國家人來得比工作快，出現貧民窟、過度都市化和一枝獨秀的首要城市；已開發國家則面對內城老舊，用都市更新改善，也引發仕紳化的爭議。

城市之間也有等級。店家要活下去需要門檻人口，顧客願意跑的距離是服務範圍。所以便利商店到處都有，百貨公司只在高級中地。

小禾的地圖多了第八層：城市。下一季：《全世界突然連在一起》。

只背一條劇情骨架

工作吸引人口 → 都市化（都市 → 都會區 → 都市帶）→ 都市問題 → 郊區化 → 開發中（過度都市化）vs 已開發（都市更新）→ 中地理論

第一幕長大都市化
第二幕生病都市問題、郊區化
第三幕兩種城過度都市化與都市更新
第四幕等級中地、門檻、服務範圍
